## 🌐 Bilingual workflow

cc-buddy-roller is built for bilingual seed work. That means you can move between English and Japanese without switching tools each time.

A simple workflow looks like this:

- write the base idea in one language
- roll a seed
- check the output in the other language
- compare tone, clarity, and fit
- keep the versions that work best

This is useful if you want the /buddy pet to feel consistent across languages while still matching each language’s natural style.

## 🧭 Tips for better results

- Keep your seed text short and clear
- Use the same format each time when testing
- Save good results as soon as you see them
- Test one change at a time
- Use plain language in both languages when you compare output
- Track the seed number or text so you can repeat a result later

If you want stable testing, avoid changing many parts at once. Small changes make it easier to see what caused the difference.
